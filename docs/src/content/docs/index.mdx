## What is included

<CardGrid>
	<Card title="Two formats" icon="document">
		`plasma-revealjs` for HTML slides and `plasma-beamer` for a PDF, from the same `.qmd`.
	</Card>
	<Card title="Figures" icon="seti:image">
		`figure` writes a plasma-plots figure for both; the `plasma-figure` shortcode shows it
		interactive in HTML and as a PDF in Beamer.
	</Card>
	<Card title="Command line" icon="seti:shell">
		`plasma-presentations new`, `build` and `install`.
	</Card>
</CardGrid>
